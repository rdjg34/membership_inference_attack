This folder contains all of the code for model6, which was completed during Milestone 3. It is run by putting all files on google drive in a "model6" folder.
Then, run model6.ipynb, which will import and call the other scripts.
Alternatively, the executed model6 is available at executed_model6.ipynb


We stored the extracted features from model6 in .csv files and placed these in the output directory.
